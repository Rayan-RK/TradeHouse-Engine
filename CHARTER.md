# CSCI 2020U Project Charter & Work Contract

## 1. Project Overview

- **Project members:** Rayan Khan, Karan Bhaskar, Mohammad Ali Jafari
- **Product Name:** TradeHouse (High-Frequency Trading Exchange)
- **Project Description:** A multi-threaded, live-market simulation where users can buy and sell simulated assets in real-time. The server features an Order Matching Engine and automated "Market Maker" bot threads to inject market volatility. The "Level Up" features include a high-contrast dark-mode JavaFX dashboard with live updating price graphs, fault-tolerant socket heartbeats, and audio cues for executed trades and market events.
- **Tech Stack:** Java, JavaFX (with Live Charting components), `java.net` Sockets for high-frequency data streaming, `java.lang.Thread` for bot and client concurrency, and File I/O for ledger and order-book persistence.
